📥 输入层
支持多种格式输入：PDF文档、图片扫描件、网页链接、直接文本粘贴
🔍 提取层
质量门禁分级：优质文本直通，模糊图片OCR识别，质量评估贯穿全程
🧠 智能分析层
四阶段分析：合同分类 → 立场初筛 → 法条对齐 → 条款生成 → 要点提取
🤖 子代理层
专业化子代理：Jev快速判定、LLM深度推理、法律检索、意图归一
💾 存储层
持久化存储：SQLite主库、法律语料索引、任务队列与重试机制
📤 输出层
结构化输出：条款发现、立场评估、法条引用、修改建议、关键要点

技术栈与关键组件

语言:Python 3.11+
框架:FastAPI (ASGI)
OCR:PaddleOCR + Tesseract
PDF:PyPDF + Fallback Parser
数据库:SQLite3
LLM:Flash + Sonnet
判定:Jev SystemOne API
检索:Bigram + IDF
队列:Job Queue + Retry
部署:WSGI/ASGI Compatible
