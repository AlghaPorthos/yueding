这是为“约定”及其后续法律事项工作台准备的研究语料快照，覆盖前期讨论的六类、30 个场景。

- 抓取日期：2026-10-02（中国标准时间）
- 维基文库法律法规：15 份，已转换成 Markdown
- 发布机关的合同与程序文书：16 份，已转换成 Markdown
- `manifest.json`：每份文件的原始网址、版本信息、字节数和 SHA-256
- `场景与资料映射.md`：六类、30 个场景的相关资料入口
- `输入输出协议.md`：供多 Agent 共享的结构化数据建议

## 使用与来源边界

维基文库文件是其网页在抓取日的 Markdown 转换，不是立法机关发布的权威版本。用于产品检索、原型和离线阅读时，请保留文件头中的来源页、修订号和时间；在对外给出法律判断前，再核对主管机关公布的现行文本及当地规则。

官方示范合同与申请书样式也不是可直接替用户签署或提交的成品。示范合同可能只适用特定地区或服务，表格中的空白项与选择项需要当事人自行核对。转换为 Markdown 后，原 DOCX/PDF 的表格布局可能简化；正式填报应以来源页的原件为准。

## 数据准备建议

1. 先把法条与示范文书分别建索引，避免把示范条款当作强制性法律规则。
2. 检索结果必须带文档名、原始网址、章节或条号、抓取日期；生成的事实还需指向用户上传的材料。
3. 对日期、金额、主体、管辖和适用地区设置独立校验；找不到依据时输出“待核实”。
4. 用户合同、身份证明和聊天记录涉及敏感信息，原型中也应尽量脱敏、控制留存。
