# 法律事项工作台输入输出协议

这是原型数据契约，供分流、材料、规则、行动和验证 Agent 交换信息。它不是法律文书模板。

```json
{
  "input": {
    "task_type": "sign | perform | dispute | apply",
    "jurisdiction": "例如：中国大陆/浙江省/杭州市",
    "user_role": "例如：承租人",
    "goal": "用户希望达到的结果",
    "documents": [
      {"id": "D1", "type": "contract | notice | receipt | chat | image",
       "date": "YYYY-MM-DD或null", "sha256": "文件哈希", "source": "用户上传或公开来源"}
    ],
    "user_assertions": [
      {"id": "F1", "text": "用户陈述", "evidence_ids": ["D1"]}
    ]
  },
  "output": {
    "extracted_facts": [
      {"text": "事实表述", "source_refs": [{"doc_id": "D1", "page": 1, "quote": "原文"}],
       "status": "supported | disputed | user_only"}
    ],
    "issues": [
      {"question": "需要确认的问题", "rule_refs": ["法律或示范文本的名称和条号"],
       "status": "supported | conflict | unknown"}
    ],
    "missing_items": ["待补充材料"],
    "actions": [{"kind": "ask | negotiate | draft | refer", "text": "下一步", "requires_user_approval": true}],
    "drafts": [{"kind": "文书类型", "body": "草稿", "fact_ids": ["F1"]}]
  }
}
```

## 验证约束

- 输出中的事实必须区分“文书直接支持”“各方有争议”“仅用户陈述”。
- 法律引用需记录原始网址、版本或抓取日期；地方规则与国家规则分层存放。
- 金额、日期和条号用确定性程序再次校验。
- 所有对外消息、签署和申请提交均需用户确认。
- 无法确认事实、规则或适用地区时，输出待核实项，不生成确定性结论。
